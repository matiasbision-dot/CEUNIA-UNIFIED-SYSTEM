# ONECLICK — publicación independiente

**Marca:** ONECLICK — All in one click.  
**Alcance de esta publicación:** únicamente ONECLICK. CEUNIA y los demás proyectos no forman parte de este sitio ni de este despliegue.  
**Autor/proponente:** Néstor Matías de la Peña.  
**Estado:** prototipo demostrativo.

## Sitio

La página principal de esta publicación es `index.html`. El sitio se despliega desde esta carpeta mediante el workflow `.github/workflows/deploy-oneclick-pages.yml`, que se activa cuando cambian archivos dentro de `ONECLICK/` en la rama `main`.

## Qué demuestra

- Una entrada sencilla para expresar una necesidad.
- Entrada escrita y, si el navegador lo admite, por voz.
- Una respuesta demostrativa local.
- Una experiencia adaptable a dispositivos móviles.

## Qué todavía no hace

No consulta proveedores, no verifica disponibilidad ni precios, no reserva, no compra, no contrata y no cobra. No transmite el pedido ni la ubicación a terceros.

## Próximo hito

Verificar que GitHub Pages complete el despliegue HTTPS. Después, probar el sitio desde un teléfono y planificar una integración real con proveedores autorizados, con precios y condiciones visibles y confirmación expresa antes de cualquier contratación.

## Principio

**Máxima resolución con mínima expresión.** Datos mínimos necesarios, recursos optimizados y resultado verificable, siempre con privacidad, consentimiento y control de la persona.
